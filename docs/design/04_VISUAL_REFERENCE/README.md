# LAST OUTPOST — VISUAL REFERENCE PACK v1.0

## 0. Mục đích

Đây là bộ tài liệu tham chiếu trực quan dành cho:
- Artist / concept artist
- UI/UX designer
- VFX artist
- Animator
- Content designer
- Claude khi triển khai asset/UI theo tài liệu

Phạm vi:
> Không viết code. Không khóa engine implementation. Chỉ khóa hướng hình ảnh và cách mô tả asset để các bên tạo đúng cùng một visual language.

Visual foundation:
> **Stylized 2.5D Cartoon + Post-Apocalyptic Adventure + Tactical Strategy**

---

# I. VISUAL NORTH STAR

Last Outpost là một thế giới hậu tận thế hoạt hình, nơi người sống sót dùng phế liệu, máy móc và sự sáng tạo để xây dựng một căn cứ ngày càng lớn mạnh.

Cảm giác mục tiêu:

- thân thiện;
- phiêu lưu;
- có cá tính;
- chiến thuật;
- có chiều sâu;
- có hy vọng;
- hậu tận thế nhưng không grimdark;
- cartoon nhưng không chibi trẻ con.

### Từ khóa bắt buộc

`stylized` · `cartoon` · `2.5D` · `isometric` · `chunky` · `expressive` · `friendly apocalypse` · `scrap-tech` · `tactical readability`

### Từ khóa cần tránh

`photorealistic` · `gritty military sim` · `grimdark` · `horror-first` · `fantasy RPG` · `full chibi` · `generic mobile strategy` · `excessive glassmorphism`

# III. CHARACTER REFERENCE

## 1. Tổng quan

Character style:
- stylized proportions;
- readable silhouette;
- expressive face;
- practical post-apocalyptic clothing;
- role-specific equipment;
- mild exaggeration.

Không chibi toàn bộ.

## 2. Commander silhouettes

### Engineer
Hình ảnh:
- backpack;
- wrench/tool;
- cooling equipment;
- utility straps;
- compact protective clothing.

Visual personality:
- practical;
- fast;
- problem solver.

### Guardian
Hình ảnh:
- stronger shoulder silhouette;
- armor;
- shotgun/rifle;
- barricade tools.

Visual personality:
- reliable;
- defensive;
- determined.

### Biologist
Hình ảnh:
- field kit;
- sample containers;
- respirator/utility gear;
- lightweight protection.

Visual personality:
- curious;
- resourceful;
- scientific.

# IV. ENEMY REFERENCE

## 1. Roster identity

Mỗi species phải có:
- silhouette riêng;
- size class rõ;
- locomotion riêng;
- attack pose riêng;
- death reaction riêng;
- color/material cue riêng.

## 2. 12 species visual direction

### Crawler
- low profile;
- many limbs;
- aggressive forward pose;
- swarm-friendly silhouette.

### Acid Bloater
- inflated body;
- visible acid sacs;
- heavy wobbling movement;
- toxic green/amber accents.

### Iron-Hide Behemoth
- massive body;
- plated armor;
- heavy steps;
- strong front silhouette.

### EMP Stalker
- compact;
- electronic organs/device;
- pulse ring visual;
- dark body + cyan energy.

### Tunnel Burrower
- drill-like / digging silhouette;
- dirt/debris trail;
- underground attack cue.

### Corpse Weaver
- thin multi-limb silhouette;
- carries/pulls corpse;
- support-unit posture.

### Scavenger Harpy
- wide wing silhouette;
- distinct aerial shadow;
- fast dive animation.

### Spore Spreader
- organic growth;
- visible spore sacs;
- drifting cloud silhouette.

### Riot Mech Mutate
- broad shield;
- asymmetrical combat silhouette;
- strong frontal defense.

### Siren Screamer
- vocal/sonic anatomy cue;
- resonant pulse;
- readable scream preparation pose.

### Colossus Titan
- extremely large silhouette;
- 4x4 gameplay footprint feeling;
- readable limbs/weak points;
- boss-grade entrance.

### Hive Mother
- giant nest-like body;
- egg/spawn elements;
- strong maternal hive silhouette.

# V. TOWER REFERENCE

## 1. Tower philosophy

Tower phải nhìn như:
> một thiết bị cơ khí thật được stylize cho game.

Không phải:
> magical fantasy turret.

## 2. Three-Tier language

### Base
Đọc ngay:
- mobility;
- stability;
- cooling;
- mount type.

### Barrel
Đọc ngay:
- damage family;
- projectile type;
- range.

### Module
Đọc ngay:
- utility;
- special interaction;
- energy behavior.

Khi ghép ba phần:
> người chơi phải nhìn thấy “đây là build của mình”.

## 3. Recommended silhouette families

- Mechanical / circular
- Heavy / rectangular
- Long-range / narrow
- Utility / compact
- Mobile / tracked
- Mounted / hanging

# VIII. UI REFERENCE

## UI character

> Clean tactical interface with cartoon-world personality.

### Surfaces
- navy/slate;
- mild texture;
- subtle depth;
- controlled transparency.

### Shapes
- rounded;
- slightly industrial;
- not overly soft;
- not aggressively military.

### Typography
- strong rounded display font for headings;
- clean sans for information;
- highly readable numbers.

### Buttons
Primary:
- cyan/teal or amber.

Secondary:
- slate/steel.

Danger:
- coral/red.

### Avoid
- huge card stacks;
- fantasy ornaments;
- excessive glow;
- excessive glassmorphism;
- UI dominating battlefield.

---

# IX. COMBAT UI REFERENCE

Battlefield should remain visually dominant.

Priority:
1. Danger
2. Current objective
3. Wave state
4. Resource shortage
5. Tactical abilities
6. Tower state
7. Secondary information

World-space UI preferred for:
- range;
- repair;
- logistics;
- hazard;
- boss weak point.

HUD keeps only continuously useful data.

---

# X. VFX REFERENCE

VFX language:
> readable first, satisfying second, spectacular third.

### Weapon fire
- short anticipation;
- clear muzzle flash;
- projectile trail;
- impact.

### Heavy weapon
- larger recoil;
- stronger sound;
- smoke/debris;
- longer recovery.

### Energy
- bright core;
- controlled glow;
- very limited color count.

### Enemy death
- no gore;
- stylized burst;
- smoke;
- dissolve;
- parts/debris when appropriate.

### Upgrade
`highlight → energy pulse → build action → completed glow`

---

# XI. MOTION REFERENCE

Every major animation should follow:

`Anticipation → Action → Impact → Recovery`

## UI
- fast open;
- soft close;
- reward pop;
- upgrade reveal.

## Tower
- recoil;
- servo/machinery motion;
- heat warning;
- reload.

## Enemy
- walk/run;
- attack wind-up;
- attack;
- hit reaction;
- death.

## Boss
- entrance;
- warning;
- attack telegraph;
- phase transition;
- defeat.

---

# XII. LIGHTING REFERENCE

Overall:
> soft stylized light + readable shadow + selective highlights.

### Day
Bright but not overexposed.

### Night
Dark mood but enough silhouette separation for gameplay.

### Outpost
Warmer practical lights.

### Hazard
Environmental color shift must not destroy enemy/tower readability.

# XXI. DO / DON'T QUICK GUIDE

## DO
- chunky silhouettes;
- expressive animation;
- colorful controlled palette;
- scrap-tech;
- clean UI;
- readable VFX;
- lively Outpost.

## DON'T
- photorealistic;
- dark muddy everything;
- hyper-military;
- fantasy magic;
- full chibi;
- gore;
- UI card overload;
- effects covering the fight.

---

# XXII. FINAL VISUAL TARGET

> **“Một game hậu tận thế mà người chơi muốn nhìn vào, chứ không phải một thế giới mà người chơi muốn thoát ra.”**

Visual phải khiến:
- Outpost đáng để quay lại;
- Commander đáng nhớ;
- Enemy dễ phân biệt;
- Tower có cá tính;
- Combat dễ đọc;
- UI thân thiện;
- progression nhìn thấy được.
